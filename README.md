# Каталог книг на Yii2

Каталог книг с несколькими авторами, загрузкой обложек, SMS-подписками на конкретного автора и публичным отчётом ТОП-10 авторов за выбранный год.

## Запуск через Docker

```bash
docker compose up -d
```

Это единственная команда: контейнер автоматически ждёт готовности MariaDB, применяет миграции и подготавливает постоянный Docker volume для обложек.

Приложение: http://localhost:8000. Демо-вход для управления каталогом: `admin` / `admin` (также доступен `demo` / `demo`). Учётные записи демонстрационные; для production подключите собственное хранилище пользователей.

## Локальный запуск

Требуются PHP 8.2+, MySQL/MariaDB и Composer.

```bash
composer install
mysql -u root -e 'CREATE DATABASE book_catalog CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci'
php yii migrate
php yii serve
```

Подключение настраивается переменными `DB_DSN`, `DB_USER`, `DB_PASSWORD`. Письма по умолчанию сохраняются в `runtime/mail`; SMTP можно настроить в `config/web.php`.

## Права

- Гость: каталог, карточки книг и авторов, отчёт, SMS-подписка на конкретного автора.
- Авторизованный пользователь: всё перечисленное плюс CRUD книг и авторов.
- Удаление автора каскадно удаляет связи и подписки, но не сами книги.

## SMSPilot

По умолчанию используется официальный ключ-эмулятор SMSPilot: API возвращает успешный результат, но реальная SMS не отправляется. Для production задайте ключ и, при необходимости, зарегистрированное имя отправителя в `.env` или окружении:

```bash
SMSPILOT_API_KEY=ваш_64_символьный_ключ
SMSPILOT_SENDER=INFORM
docker compose up -d
```

Номера подписчиков вводятся в международном формате, например `79991234567`. Документация: https://smspilot.ru/apikey.php
